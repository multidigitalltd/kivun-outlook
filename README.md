# Kivun Outlook Board – לוח כיתות מאאוטלוק לוורדפרס

תוסף וורדפרס שמסנכרן את יומן ה-Outlook שבו מנוהלות הכיתות לטבלה יומית מעוצבת ("מה הכיוון היום? לו"ז יומי").
הטבלה מוצגת בדף פומבי באתר, ויש גם כתובת מסך מלא להקרנה על המסך שבכניסה.

## מה התוסף עושה

- **סנכרון אוטומטי מאאוטלוק** כל X דקות (ברירת מחדל: 10). יש שתי אפשרויות:
  - **קישור ICS מפורסם**: הכי פשוט, ולא צריך הרשאות מנהל ב-Microsoft 365.
  - **Microsoft Graph API**: לארגונים שבהם פרסום יומן חסום, או כשלכל כיתה יש תיבת חדר (Room mailbox).
- **שיבוץ אוטומטי לכיתות** לפי שדה *מיקום* של הפגישה (או קטגוריה, או נושא). אפשר גם לשייך יומן שלם לכיתה.
- **עיצוב "לוח יומי 8b"** (מגרסה 2.0): כרטיס לכל כיתה עם חלק לבוקר ולאחר הצהריים, שעון חי, תאריך לועזי ועברי.
  - כל שיעור מסומן אוטומטית לפי השעה: **עכשיו** (רקע אדום), **בקרוב** (מתחיל בתוך שעה) או **הסתיים**. חלק ריק מוצג כ"פנוי".
  - השעון מציג שניות רצות ומסונכרן לשעון של שרת האתר, כך שהשעה נכונה גם אם השעון של המסך מכוון לא נכון. המצבים מתעדכנים כל 10 שניות.
  - התאריך העברי מוצג באותיות (למשל ח׳ בחשוון תשפ״ז).
- **מסך הקרנה** (`/kivun-board/`):
  - נמתח לכל גודל מסך ביחס 16:9.
  - מתעדכן לבד בלי לטעון את הדף מחדש, ועובר ליום הבא בחצות.
  - מעביר בין עמודים כשיש הרבה כיתות.
  - מסתיר את סמן העכבר. לחיצה על המסך עוברת למסך מלא.
- **שורטקוד** `[kivun_board]` שמציג את הלוח בכל דף באתר. בטלפון הוא עובר לתצוגה מותאמת.
- **שורטקוד שבועי** `[kivun_week]` שמציג שבוע מיום ראשון עד חמישי (מיום חמישי: את השבוע הבא), שורה לכל יום ועמודה לכל כיתה (ראו [תצוגה שבועית](#תצוגה-שבועית)).
- **פרטיות**: פגישות שמסומנות "פרטי" באאוטלוק לא מוצגות. מוצגים רק נושא הפגישה והשעות.
- אם הסנכרון נכשל, ממשיך להופיע המידע האחרון שהתקבל, ובמסך ההגדרות מופיעה השגיאה.

## התקנה

1. מכווצים את התיקייה `kivun-outlook-board` לקובץ ZIP.
2. בוורדפרס: תוספים ← הוספת תוסף ← העלאת תוסף ← מעלים את ה-ZIP ← הפעלה.
3. נכנסים ל**הגדרות ← לוח כיתות Outlook**.

## חיבור לאאוטלוק

### אפשרות א': קישור ICS (מומלץ להתחלה)

1. ב-Outlook באינטרנט: ⚙️ הגדרות ← לוח שנה ← **לוחות שנה משותפים**.
2. בחלק **"פרסם לוח שנה"** בוחרים את היומן ואת ההרשאה **"יכול להציג את כל הפרטים"**, ולוחצים "פרסם".
3. מעתיקים את קישור ה-**ICS** ומדביקים אותו בהגדרות התוסף.

אם לכל כיתה יש יומן נפרד, מוסיפים שורה לכל יומן ואת שם הכיתה אחרי קו אנכי:

```
https://outlook.office365.com/owa/calendar/.../calendar.ics | מחשבים
```

> שימו לב: Outlook מעדכן את הקישור המפורסם בהשהיה של עד כמה דקות.

### אפשרות ב': Microsoft Graph

1. ב-[Entra ID](https://entra.microsoft.com): App registrations ← New registration.
2. API permissions ← Microsoft Graph ← **Application** ← `Calendars.Read` ← **Grant admin consent**.
3. Certificates & secrets ← New client secret.
4. בהגדרות התוסף ממלאים Tenant ID, Client ID, Client Secret ותיבות דואר (אחת בכל שורה, ואפשר להוסיף `| שם כיתה`).

> מומלץ להגביל את האפליקציה רק לתיבות הרלוונטיות בעזרת
> [Application Access Policy](https://learn.microsoft.com/graph/auth-limit-mailbox-access).

## הגדרת כיתות

כותבים כיתה אחת בכל שורה, לפי סדר התצוגה בטבלה:

```
שם הכיתה | תת-כותרת | מילות התאמה נוספות
יועץ משה
מחשבים | | חדר מחשבים, מעבדה
הר חוצבים | קומה 0 | חוצבים
```

פגישה משובצת לכיתה כששם הכיתה או אחת ממילות ההתאמה מופיעים בשדה **מיקום** שלה באאוטלוק.
פגישות שלא שובצו לאף כיתה מופיעות ברשימה במסך ההגדרות, וכך קל לראות אילו מילות התאמה חסרות.

פגישה שמתחילה לפני **שעת המעבר** (ברירת מחדל 14:00) מוצגת בעמודות "בוקר". פגישה שמתחילה מאוחר יותר מוצגת ב"אחה"צ".

## הקרנה על המסך

- פותחים בדפדפן של המסך את הכתובת `https://האתר-שלכם/kivun-board/`. הכתובת מופיעה גם במסך ההגדרות.
- כדי שהמסך ייפתח במסך מלא אוטומטית אחרי הדלקה, מפעילים Chrome במצב קיוסק:
  `chrome --kiosk https://האתר-שלכם/kivun-board/`
- כדי להציג יום אחר, מוסיפים לכתובת סימן שאלה ואת התאריך בכל כתיב: `?13.10.2026`, `?13/10`, `?2026-10-13`, `?מחר`. אפשר לבחור תאריך עד 60 יום קדימה.

אם יש באתר תוסף קאש (WP Rocket, LiteSpeed וכו'), מחריגים מהקאש את `/kivun-board/` ואת `/wp-json/kivun-board/`.

## תצוגה שבועית

השורטקוד `[kivun_week]` מציג שבוע אחד, מיום ראשון עד יום חמישי: שורה לכל יום ועמודה לכל כיתה, ובכל תא השיעורים של אותו יום לפי סדר השעות.

- **איזה שבוע מוצג**: מיום ראשון עד יום רביעי מוצג השבוע הנוכחי. מיום חמישי (וגם בשישי ובשבת) מוצג השבוע הבא.
- אין אפשרות לבחור שבוע אחר, לא בעמוד ולא דרך הכתובת.
- היום הנוכחי מודגש באדום. שיעור שמתקיים עכשיו מסומן באדום, ושיעור שהסתיים מוצג באפור.
- הטבלה מתעדכנת לבד בלי לטעון את הדף מחדש, ועוברת לשבוע הבא ביום חמישי בחצות.
- בטלפון כל יום מוצג ככרטיס נפרד, ורק הכיתות שיש בהן שיעורים מופיעות.

### פרטים שמופיעים רק בלוח השבועי

כדי להוסיף לשיעור פרטים שיופיעו רק בלוח השבועי, כותבים אותם בנושא הפגישה באאוטלוק אחרי הסימן `@`. כל `@` מתחיל שורה חדשה:

```
סדנת אנגלית @ מימון: משרד העבודה @ 40 שעות
```

- בלוח היומי ובמסך ההקרנה מופיע רק מה שלפני ה-`@`: **סדנת אנגלית**.
- בלוח השבועי מופיע אותו שם, ומתחתיו שורה לכל פרט: *מימון: משרד העבודה*, *40 שעות*.
- בפגישה חוזרת מספיק לכתוב את הפרטים פעם אחת על כל הסדרה. מופע בודד שהנושא שלו שונה בנפרד שומר על הנושא שלו, ואת הפרטים מוסיפים גם לו.
- הסימן `@` תמיד מפריד בין השם לפרטים, ולכן לא כותבים בנושא כתובת מייל.
- גם הלוח השבועי פומבי. לא כותבים בפרטים מידע שלא כל מי שיש לו את הקישור צריך לראות.

אפשר לשנות את הכותרות:

| אפשרות | מה היא עושה | דוגמה |
| --- | --- | --- |
| `title` | הכותרת. המילה האחרונה מוצגת באדום. ברירת מחדל: מה הכיוון השבוע? | `[kivun_week title="מה מתוכנן השבוע?"]` |
| `subtitle` | השורה שמתחת לכותרת. ברירת מחדל: לו״ז שבועי. | `[kivun_week subtitle=""]` |
